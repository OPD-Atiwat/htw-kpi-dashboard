# 🦔 แนวทาง Key Message / Category / Script — ออฟฟิศนี้เฮงซวย (สัตว์)
> สรุปจากข้อมูลจริง (FB/Meta, dashboard) + เนื้อหาหนังสือ · เล่มต่ำเป้าเพราะอะไร และทำต่อยังไง

---

## 0. ปัญหา (ตั้งแต่บรีฟแรก)
- ROAS FB ดิ่งจาก **2.21 (พ.ค.) → 1.21 (มิ.ย.)** ขณะที่เส้นกำไรอยู่ที่ **ROAS ≥ 2.3** (%Ads เพดาน ~43%) → มิ.ย. ขายขาดทุนเกือบทุกคลิป
- สาเหตุ: มิ.ย. เททั้งงบไปหมวด **Solution (สอนวิธีรับมือ) + Painpoint (เจ็บล้วน)** ซึ่งเป็น 2 หมวดที่ ROAS แย่สุด

## 1. WHO — กลุ่มเป้าหมายจริง (ยืนยันด้วยข้อมูล)
| ช่วงอายุ (target แคบ) | ROAS |
|---|---|
| 25–34 (ค่อน GenZ) | 1.92 ❌ ต่ำสุด |
| 35–44 (GenY) | 2.13 ✅ |
| 45–54 | 2.23 ✅ |

**สรุปตรงกับสมมติฐาน:** GenZ เจอ Toxic แล้ว "ลาออกจบ" ไม่ต้องซื้อคู่มือ → **คนซื้อจริงคือ GenY 35+ ที่เปลี่ยนงานยาก ต้องอยู่ให้เป็น**
→ **เลิกทำ Visual/โทน "เฟียส–สายสู้"** (ดึง GenZ ที่ไม่ซื้อ) เปลี่ยนเป็นโทน **"เข้าใจ–เยียวยา–มีทางรอด"**

**โครงหัวกรวยที่ถูกต้อง:** `Insight (อยากรู้+ตัวตน) → Review (เห็นของ ลดเสี่ยง) → Promotion (เหตุผลซื้อตอนนี้)`
เล่มนี้ปิดการขายในแชทเยอะ (2.2 แชท/ออเดอร์) → Insight/Review เปิดแชท, Promotion ปิด

## 3. KEY MESSAGE — สูตรที่ห้ามพลาด
ทุกคลิปต้องครบ 4 จังหวะ (ที่ มิ.ย. หายไป):
1. **Painpoint สั้น** — แตะความเจ็บ (3 วิ)
2. **Identify** — ระบุ "สัตว์/เล่ห์" ให้เป็นชื่อ (identity hook — คนอยากรู้/อยากแท็ก)
3. **Book = ทางออก** — หนังสือช่วย "รู้ทัน + รับมือ" ยังไง (ห้ามสอนจบในคลิป ให้แค่ teaser)
4. **เหตุผลซื้อตอนนี้** — ส่งฟรี/ลายเซ็น/จำนวนจำกัด + CTA ทักแชท/กดตะกร้า

> ❌ อย่าทำ: เจ็บล้วน (Painpoint) / สอนครบจบในคลิป (Solution)
> ✅ ให้ทำ: เจ็บ → ตั้งชื่อปัญหา → หนังสือคือคำตอบ → ปิดด้วย offer

**จุดต่างที่ขายได้ (จากบทที่ 5 ของเล่ม):** หนังสือไม่ได้บอกแค่ "สู้" แต่บอกว่า **"ตัวไหนสู้ได้ ตัวไหนควรเดินจากอย่างผู้ชนะ"** — ตรงนี้ตอบโจทย์ "เหยื่อที่รับมือ CEO สิงโตบ้าอำนาจไม่ได้" ที่คอนเทนต์ "สอนสู้" ทั่วไปตอบไม่ได้

## 4. SCRIPT TEMPLATE (ต่อยอดจากเนื้อหาจริงในเล่ม)

**เนื้อหาที่ดึงได้จากหนังสือ — 8 เล่ห์ Toxic + วิธีรับมือ (วัตถุดิบ Insight ชั้นดี):**
1. ปั่นความจริง (Gaslighting) → รับมือ: จดบันทึก/หาพยาน กันโดนล้างสมอง
2. โยนความผิด · 3. เงียบใส่ (silent treatment) · 4. ก้าวร้าวแฝง (จี้ใจดำแต่ทำเป็นหวังดี)
5. เคลม/ขโมยผลงาน · 6. จ้องจับผิด · 7. ดึงดราม่าเข้าตัว · 8. ทำเรื่องไม่สำคัญให้ใหญ่

**14 สัตว์ Toxic** (หมาบ้า, ปลาไหล, แมงมุมบงการ, เหยี่ยวจับผิด, แรดเคลมงาน, สิงโตบ้าอำนาจ, แม่เป็ดลูกรัก, กิ้งก่ากลับกลอก ฯลฯ) → 1 ตัว = 1 คลิป Insight

**แม่แบบสคริปต์ (VDO ~30 วิ):**
```
[Hook 0-3วิ] เปิดด้วย text + เหตุการณ์: "เคยเจอ___ ในออฟฟิศไหม?"
[ระบุ 3-12วิ] นี่แหละ "[ชื่อสัตว์/เล่ห์]" — พฤติกรรมคือ ___ (ยกตัวอย่างสั้น)
[Book teaser 12-22วิ] หนังสือ ออฟฟิศนี้เฮงซวย (สัตว์) บอกวิธีรับมือ___ ไว้ (เปิดแค่ครึ่งทาง)
   + เส้นต่าง: "บางตัวสู้ได้ บางตัวรู้ว่าเมื่อไหร่ควรเดินจาก"
[CTA 22-30วิ] + offer (ส่งฟรี/ลายเซ็น) → กดตะกร้า/ทักแชท
```

## 5. คลังหัว Key Message ถัดไป (พร้อมยิง — ตาม 3 หมวดที่ชนะ)
**Insight (ตัวเปิด):**
- "หัวหน้าคุณเป็นสัตว์ตัวไหนใน 14 ตัวนี้" (quiz/identity)
- "เล่ห์ Gaslighting ที่ทำให้คุณคิดว่าตัวเองผิด ทั้งที่ไม่ผิด"
- "เพื่อนร่วมงานที่ 'จี้ใจดำแต่ทำเป็นหวังดี' = สัตว์ประเภทนี้"
- "CEO บ้าอำนาจ (สิงโต) — ตัวที่สู้ตรงๆ ไม่ได้ ต้องรับมือแบบไหน"

**Review (ตัวกลาง ลดเสี่ยง):**
- รีวิวสายเยียวยา ต่อยอดจากแชมป์ "กู้คืนสุขภาพใจในที่ทำงาน Toxic"
- Unboxing + "ไอเทม must have บนโต๊ะคนทำงาน"
- รีวิวจากคนวัย 35+ ที่ "เปลี่ยนงานไม่ได้แต่รอดมาได้"

**Promotion (ตัวปิด):**
- "ส่งฟรีเฉพาะช่องทางนี้" (สูตรเดียวที่รอดใน มิ.ย. ROAS 2.05) — หมุนเป็นประจำ
- รอบลายเซ็น/บุ๊กมาร์กจำนวนจำกัด

## 6. เรื่องการยิงแอด
- ครีเอเตอร์หลัก: **หมิว (ROAS 2.07) + ริว (1.95)** — มิ้น/อินฟลู ROAS ต่ำ ใช้เท่าที่จำเป็น
- **หยุดอินฟลู** (Influ/Central/สต็อป ROAS 0.85–1.23 ขาดทุน)
- Target: ขยับน้ำหนักไป **35–54** ลดงบกลุ่ม 25–34
- Guardrail: **ROAS < 2.3 = ลด/ปิดทันที**
- รี-รัน 3 คลิปแชมป์ (รู้ทันสัตว์ร้าย 2.61 / กู้คืนสุขภาพใจ 2.31 / 12 Toxic Animals 2.33) + ขยาย audience ใหม่แก้ CPM แพง
