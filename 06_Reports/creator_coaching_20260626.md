## 👤 รายคน

### หมิว — ROAS 1.70 ❌ / CPM ฿86.8 ✓
- **ผลงาน:** spend ฿32,053 (แอดเยอะสุดในทีม), rev ฿54,343, 134 ออเดอร์ — volume ดีแต่ ROAS ยังไม่ถึง 2x
- เล่นหลัก: กับดัก (ROAS 1.77) + สัตว์ (1.73) — สองเล่มสูสีกัน
- **โค้ช:**
  1. แอดเยอะแต่ ROAS เกาะ ~1.7 = เริ่มถึงเพดาน FB ของหมิว ลอง **หั่น budget ตัวที่ ROAS < 1.5 ออก** เอางบไปอัดตัวชนะ
  2. เล่ม Promotion/Ghostly/E-Book ที่ rev = 0 → **ปิดหรือพักทันที** อย่าปล่อยกินงบ
- **โฟกัสสัปดาห์หน้า:** ดัน ROAS กลับ ≥ 2x โดยไม่ลด volume เกินไป — คุมงบเล่มแพ้

### มิ้น — ROAS 1.62 ❌ / CPM ฿97.1 ✓ (ใกล้เพดาน)
- **ผลงาน:** spend ฿15,940, rev ฿25,771, 61 ออเดอร์
- ของเด่น: **"ขอใช้ชีวิตที่เหลือ เพื่อตัวเอง" ROAS 3.21** 🔥 และ Promotion 3.24 — แต่ทั้งคู่ spend ยังน้อย
- ของฉุด: สัตว์ ROAS 0.34 (จ่าย ฿922 ได้ ฿310)
- **โค้ช:**
  1. **เทงบเพิ่มที่ "ขอใช้ชีวิตที่เหลือฯ"** — ตัวนี้ ROAS 3x แต่ใช้แค่ ฿1,786 ยังสเกลได้อีกเยอะ
  2. CPM ใกล้แตะ ฿100 — เช็คครีเอทีฟตัวสัตว์ที่ ROAS 0.34 **พักไว้ก่อน** อย่าให้ดึง CPM รวมขึ้น
- **โฟกัสสัปดาห์หน้า:** สเกลตัวชนะ (ขอใช้ชีวิตฯ) ให้ขึ้นเป็นเสาหลัก, ตัด สัตว์ ที่ขาดทุน

### ริว — ROAS 1.18 ❌ / CPM ฿58.1 ✓ (ต่ำสุด=ดี)
- **ผลงาน:** spend ฿15,836, rev ฿18,738, 47 ออเดอร์ — **ROAS ต่ำสุดในทีม ต้องโฟกัส**
- กับดัก 1.30, สัตว์ 1.08, Shopify rev 0
- **โค้ช:**
  1. CPM ดีสุดในทีม (฿58) = ครีเอทีฟดึงคนเก่ง **แต่ปิดออเดอร์ไม่ได้** → ปัญหาอยู่ที่ปลายทาง (offer/หน้าขาย/แคปชั่น CTA) ไม่ใช่ตัวคลิป ลองปรับ CTA + ปักโปรให้ชัด
  2. Shopify spend ฿599 rev 0 → **ปิด**
- **โฟกัสสัปดาห์หน้า:** เอา CPM ถูกของตัวเองมาแปลงเป็นยอด — ดัน ROAS จาก 1.18 → ≥1.5 ก่อนเป็นขั้นแรก

## 🧭 สรุปทีม + โฟกัสสัปดาห์หน้า
1. **ROAS FB ต่ำกว่า 2x ทั้งทีม** — เรื่องด่วนคือคุมงบเล่มแพ้ (rev 0 / ROAS <1) ปิด/พักทันที ทั้ง หมิว(Promo,E-Book,Ghostly) ริว(Shopify) มิ้น(สัตว์)
2. **CPM ทุกคนผ่าน** — ครีเอทีฟไม่ใช่ปัญหา ปัญหาคือ conversion ปลายทาง โดยเฉพาะ **ริว**
3. **มิ้น มีตัวชนะ ROAS 3x** ("ขอใช้ชีวิตที่เหลือฯ") — สั่งสเกลเป็น priority
4. รอ **TT มิ.ย. sync** ก่อนตัดสิน on/off track เทียบ goal (ตัวเลขจริงรวม TT จะสูงกว่านี้มาก)
